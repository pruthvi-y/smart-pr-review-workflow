# Changelog

## 0.8.0 - Stage 8

- Added MCP v2 server exposing GitHub pull-request tools.
- Added MCP client using the official Python SDK.
- Added `inspect-mcp` command for tool discovery.

- Added state field for integration mode.
- Added developer dependency group with pytest.
- Added architecture, MCP learning notes, roadmap, and contribution guidance.
- Kept GitHub comment posting opt-in by default.
